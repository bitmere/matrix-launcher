# Matrix public-launch feature audit

Source snapshot: supplied file copy identified as fc4d54c1, version 2.7.5 / 154, stable. This is a source audit, not a live account, TV or performance certification. Each bullet is one implemented feature with its screen and source. README claims were checked against handlers, adapters and policies rather than inherited.

The installed ID, personal_home preferences, version, signing and release workflow remain unchanged. Optional integrations require compatible services/apps and user configuration. Paths below are repository-relative.
