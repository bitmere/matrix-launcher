# Local and Commons wallpapers

Open Settings → Wallpapers. In stable 1.2.0, Import pictures uses Matrix’s remote-friendly album menu and shared thumbnail grid. The system picker opened on TCL but its Photos/Albums controls were not usable with the remote; that route has been removed. It copies images into Matrix's own collection, so later rotation works offline. **Choose saved wallpaper** shows thumbnails of saved imports, old retained pictures and Commons downloads. Selecting a picture applies it until the next rotation interval; choosing a picture outside the active source switches Source to all saved pictures. Source selects all saved images, imports/earlier saved images, Commons only, or focused-artwork color. Rotation defaults to 30 minutes and only ticks while the launcher is visible. Empty collections fall back to the focused artwork's ambient colors.

Download landscapes fetches Wikimedia Commons featured landscape photos with no account/key. Daily Commons downloads is opt-in; enable it to check once every 24 hours while the launcher is visible. Up to five new pictures are added per refresh, with at most 20 Commons pictures cached. Manual retries have a one-minute cooldown, including failures, to avoid repeated API requests. The search advances through a bounded result window, returning to the start when exhausted. It is not a promise of five new images every day.

Each import request and the local collection are bounded to 20 images; retention protects the currently selected local picture. The device browser requests read-only photo access only on demand: READ_MEDIA_IMAGES on Android 13+, selected-photo support on Android 14+, or READ_EXTERNAL_STORAGE capped at API 32. It never requests videos, all-files access or write access. Denial leaves shared-image imports, saved pictures and Commons available. Copies need no persistent URI grants; photo access can be revoked afterwards in Android app permissions. Collections are bounded to 20 imported images, excluding the retained earlier-download archive. Image transfers are bounded to 8 MiB each (imports 10 MiB) and stored at a maximum 1920×1080 using the existing sampled JPEG path. This is Full HD, not original-resolution 4K storage. Commons downloads skip portrait, undersized, extreme panorama, unsupported and missing-attribution results. Downloads run sequentially off the UI thread; network failure retains the existing collection. No arbitrary website scraping or background download service is used.

Wallpaper credits lists creators/licenses for cached Commons pictures. Select a credit to scan its original file page on your phone, including complete author details and the applicable license. Title, author, license, source URL and license URL are stored alongside every image. Matrix resizes and JPEG-encodes these images; credits identify that modification. Only recognized CC BY, CC BY-SA, CC0 or public-domain labels with Creative Commons license URLs are accepted. Some otherwise valid Commons files will be skipped conservatively. Imported pictures and earlier downloads remain subject to their original licenses.

The source uses the documented [MediaWiki imageinfo API](https://www.mediawiki.org/wiki/API:Imageinfo) and follows [API etiquette](https://www.mediawiki.org/wiki/API:Etiquette) with an identifying User-Agent, batched metadata query and serial downloads. Commons content must be reused under [each file's license](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia).

Reddit setup, refresh tokens, subreddit selection and network requests were removed in beta 27. On upgrade, Matrix removes its stored Reddit credentials and preferences but leaves old images and the selected wallpaper path intact. The former directory is read only as an offline archive. This cannot revoke an authorization on Reddit's servers; revoke it separately in your Reddit account if one was previously granted. No account or Home-capture settings are changed.

## Pictures downloaded with Downloader or a file manager

Open the downloaded image and choose **Matrix wallpaper** in Open with, or Share the image to Matrix wallpaper. The confirmation screen previews the image; Import copies it into Matrix, and Cancel leaves the collection unchanged. Import does not automatically replace the selected background. Return to Settings → Wallpapers → Choose saved wallpaper to use it.

The sender must share a readable content URI with its normal temporary read grant. Only image VIEW/SEND/SEND_MULTIPLE payloads are accepted; file paths, HTTP links, other MIME types and Matrix's private theme provider are rejected. No incoming Intent is forwarded. Imports reuse the same 10 MiB bound, sampled decode, Full HD JPEG path and selected-image retention as the picker. A process-wide wallpaper mutex serializes collection operations across the Home and import Activities.

If a downloaded image is absent from Android's media index, use Downloader's Open with/Share route. The browser shows up to 500 recent indexed images, grouped into albums, and filters files above the 10 MiB import bound. Refresh reloads the index and access state. Android 14 partial access is respected; Change photo access lets the user request a different grant. No recurring scan or background media observer is installed. Actual provider URI grants and supported file formats remain necessary.

References: [Android photo-picker access model](https://developer.android.com/training/data-storage/shared/photo-picker), [receiving shared images](https://developer.android.com/develop/ui/compose/sharing/receive).
